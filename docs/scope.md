# Project Scope

Defines what is in scope and out of scope for the project and tracks milestone status. Changes to project scope
require an owner decision recorded in [docs/decisions.md](decisions.md).

## In Scope

- Offline, single-player Windows (x64) Unity game.
- Incremental, versioned milestones (`vX.Y.Z`) each defined by an approved product spec in `docs/specs/vX.Y.Z.md`.

## Out of Scope (Current)

- Online multiplayer, accounts, telemetry, or cloud services.
- Third-party modding SDKs (unless explicitly introduced by a future approved spec).
