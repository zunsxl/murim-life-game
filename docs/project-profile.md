# Project Profile

Authoritative project facts read by agents and deterministic quality gates. When the repository at the reviewed
revision disagrees with this profile, the repository wins.

| Topic | Facts |
|---|---|
| Product | Offline, single-player Unity game set in the martial world of Murim. Delivered as a Windows (x64) player build. |
| Stack | Unity 6.3 LTS (`6000.3` stream; exact patch pinned in `ProjectSettings/ProjectVersion.txt`), URP (Forward), Input System, uGUI/TextMesh Pro, Unity Test Framework (exact versions pinned in `Packages/manifest.json` and `Packages/packages-lock.json`), C# 9, Mono scripting backend. Standalone Core tests build with the .NET 10 SDK pinned in `global.json` and NUnit packages locked in `tests/Core/*.csproj`. |
| Architecture rules | `Murim.Core` (`Assets/Scripts/Core/`, `.asmdef` with `"noEngineReferences": true`) holds pure-C# game rules and state. `Murim.View` (`Assets/Scripts/View/`) handles rendering, input, and UI and calls Core; Core never references View, Editor, or `UnityEngine`. `Murim.Editor` (`Assets/Editor/`) holds build and import tooling only. |
| Invariants | Seeded determinism: the same seed produces the same simulation/world output across runs (no unseeded RNG, no wall-clock time, no threading or CPU-dependent transcendental math in deterministic Core logic). Tunables live in JSON under `Assets/StreamingAssets/Data/` with `schemaVersion`; missing or invalid files log a warning and fall back to built-in defaults. |
| Engineering standards | Follow `.editorconfig` at the repository root. No per-frame heap allocations, LINQ, or scene lookups (`FindObjectOfType`/`Camera.main`) in `Update`/`LateUpdate`/`FixedUpdate`. Reference Unity layers by index constants, not `LayerMask.NameToLayer`. Use `CultureInfo.InvariantCulture` for numeric parsing. `Murim.Core` compiles with `<TreatWarningsAsErrors>true</TreatWarningsAsErrors>`. |
| Art and assets | Art direction lives in [docs/art-direction.md](art-direction.md) and version reference images in `docs/references/` (never shipped). Inventory IDs use `ART-NNN`. Production art credits live in [Assets/Art/ART_README.md](../Assets/Art/ART_README.md). |
| Configuration and data | JSON files under `Assets/StreamingAssets/Data/`, each containing an integer `schemaVersion` and capped at `64 KiB` (`65536` bytes). Malformed, oversized, or schema-mismatched files warn and fall back to built-in defaults. |
| Documents of authority | Product specs `docs/specs/vX.Y.Z.md`; technical specs `docs/specs/vX.Y.Z-technical.md`; decisions [docs/decisions.md](decisions.md); vision [docs/vision.md](vision.md); scope [docs/scope.md](scope.md); art direction [docs/art-direction.md](art-direction.md); this profile. |
| Roles and authority | The owner approves specs, chooses art options, waives gate findings, and merges PRs. Branches: `vX.Y.Z-spec`, `vX.Y.Z-impl`, `vX.Y.Z-impl-ARCH-NNN`, `vX.Y.Z-docs`; never `vX.Y.Z` (release tags). |
| Verification | Deterministic quality gates: `python quality-gates/run_gates.py <gate> ...` (see [quality-gates/README.md](../quality-gates/README.md)). Build/test runner (when initialized): `tools/verify-all.sh` with suites `core`, `engine`, `art`, `build`. Focused run: `bash tools/verify-all.sh --suite <name> [--filter <expr>]`. Full run: `bash tools/verify-all.sh`. Unity suites read the editor path from the `UNITY_EDITOR` environment variable. |
| Path-to-suite map | `Assets/Scripts/Core/**`, `tests/Core/**` -> `core`. `Assets/StreamingAssets/Data/**` -> `core` + `engine` (`ConfigLoading`). `Assets/Scripts/View/**`, `Assets/Shaders/**`, `Assets/Scenes/**`, `Assets/Resources/Materials/**`, `Assets/Resources/Prefabs/**`, `Assets/Tests/Engine/**` -> `engine`. `Assets/Settings/**` -> `engine`. `Assets/Resources/Art/**`, `Assets/Editor/ArtImportPostprocessor.cs`, `Assets/Editor/Art/**`, `Assets/Tests/Engine/Art/**` -> `art`. `Assets/Editor/BuildScript.cs` -> `build`. `tools/verify-all.sh` -> `--self-test`. `Packages/**`, `ProjectSettings/**`, `global.json`, `tests/Core/*.csproj`, `tools/dotnet/**` -> full run. `docs/**`, `agents/**`, `tests/playtest/**` -> none. |
| Threat model inputs | Untrusted/shared build data (`Assets/StreamingAssets/Data/*.json`), command-line flags (`-seed`), local contributor tooling (`tools/verify-all.sh`, `dotnet`, Unity batch mode), and package manifests. Release player builds must exclude `Development`, `AllowDebugging`, and Profiler options. Game logs must exclude usernames, home paths, and machine names. |
| Gate policy | Deterministic gates exit `0` (`PASS`), `1` (`FAIL` on unwaived `CRITICAL`/`HIGH` findings), or `2` (`BLOCKED`). Medium and Low findings do not block. Waivers require `WAIVED: <FINDING-ID>` in `docs/decisions.md`. |
